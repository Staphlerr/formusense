Foto kamu, pilihan kamu

Pilih cara analisis foto. Analisis lokal memakai MediaPipe dan OpenCV di server demo. Jika kamu memilih cadangan AI, foto dapat dikirim ke penyedia API hanya saat analisis lokal gagal. Foto tidak disimpan sebagai file di server; profil dan koordinat bibir disimpan sementara dalam sesi. Salinan kecil foto tersimpan di tab browsermu untuk mencoba shade. Hasilnya bisa kamu koreksi.

Analisis ini bukan pemeriksaan kesehatan. Kamu bisa lanjut tanpa foto dan mengisi profil manual.
