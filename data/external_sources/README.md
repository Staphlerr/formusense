# External Source Downloads

This folder stores datasets and source references downloaded from public sources.

Downloaded locally:

- `the_pudding_makeup_shades/`
- `nature_shampoo_formulation/`
- `capstone_colors_original/`

Not downloaded automatically:

- Kaggle datasets, because this machine does not have Kaggle CLI or Kaggle credentials configured.
- The 358 MB Figshare formulation image ZIP, because it is large and not directly useful for the lipstick shade demo.
- The full Capstone Colors original image folder, because it is about 100.9 MB and the CSV metadata is more useful for the hackathon prototype.

See `../DATASET_MANIFEST.md` for how each source should be used.
